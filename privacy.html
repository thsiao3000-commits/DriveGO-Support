一、資料收集

開車GO 不會收集、儲存或傳輸任何個人可識別資料。本應用程式不需要使用者註冊或登入，不使用任何第三方分析工具、廣告框架或追蹤 SDK。

二、本機儲存（UserDefaults）

App 使用 iOS 本機 UserDefaults 儲存以下偏好設定，資料僅存在於您的裝置，不會上傳到任何伺服器：

  • 收藏的景點清單（以景點 ID 字串儲存）
  • 語言偏好（zh / en / ja / ko）
  • 外觀模式偏好（淺色 / 深色）
  • 拉霸縣市勾選狀態

三、網路存取

App 的景點與停車場文字資料皆內建於 App，瀏覽文字不需要網路。以下情境會產生網路請求：

  • 景點圖片：景點詳情頁與列表縮圖從 TDX 提供的 URL 載入圖片（例如 travel.taichung.gov.tw、miaoli.gov.tw、travel.taipei 等政府觀光網站），圖片透過系統 URLCache 快取；
  • 外部連結：當您點擊景點描述下方的「資料來源：維基百科」或「AI 生成，參考：XXX」連結時，會以系統瀏覽器開啟該外部網站；
  • 地圖導航：點擊景點或停車場的「導航」按鈕時，會將座標傳給系統的 Apple Maps，由 Apple Maps 處理導航。

以上網路請求均不包含任何使用者識別資訊。App 本身不會向任何開發者控制的伺服器發送請求。

四、資料來源的 AI 處理

景點與停車場的 en / ja / ko 翻譯、以及部分景點中文介紹，是在伺服器端 ETL 流程預先使用 OpenAI（gpt-4o-mini 與 gpt-5.4-mini + 網路搜尋）生成後再打包進 App。App 執行時不會呼叫 OpenAI API，也不會將任何使用者資料送至 OpenAI。

五、第三方服務

本應用程式不使用任何第三方分析、廣告或追蹤 SDK（不含 Google Analytics、Firebase Analytics、Facebook SDK、廣告 SDK 等）。

六、兒童隱私

開車GO 不會收集任何使用者的個人資訊，適合 4 歲以上所有年齡層使用。

七、隱私權政策變更

如有變更，將於 App 更新版本與本頁面同步公布。

八、聯絡方式

如對本隱私權政策有任何疑問，請來信：thsiao4000@gmail.com

English Version

1. Data Collection

開車GO (DriveGO) does not collect, store, or transmit any personally identifiable information. The App requires no registration or login, and uses no third-party analytics, advertising frameworks, or tracking SDKs.

2. Local Storage (UserDefaults)

The App uses iOS UserDefaults to save the following preferences locally on your device. These never leave your device:

  • Favorited attraction IDs
  • Language preference (zh / en / ja / ko)
  • Appearance mode (Light / Dark)
  • Selected-city state for the spinner

3. Network Access

All text data (attractions, parking lots, descriptions) is bundled into the App and works without a network connection. The following actions may trigger network requests:

  • Attraction photos: loaded from TDX-provided URLs hosted on Taiwan government tourism sites (e.g. travel.taichung.gov.tw, travel.taipei). Images are cached by the system URLCache.
  • External links: tapping the "Source: Wikipedia" or "AI-assisted, source: XXX" link under a description opens the external site in the system browser.
  • Map navigation: tapping the Navigate button passes coordinates to Apple Maps for driving directions.

None of these requests include any user identifier. The App itself does not contact any developer-controlled server.

4. AI Processing of Source Data

English / Japanese / Korean translations and some Chinese descriptions are pre-generated offline using OpenAI (gpt-4o-mini and gpt-5.4-mini with web search) as part of the ETL pipeline and bundled into the App. The App does not call the OpenAI API at runtime and does not send any user data to OpenAI.

5. Third-Party Services

This App does not use any third-party analytics, advertising, or tracking SDKs (no Google Analytics, Firebase Analytics, Facebook SDK, ad SDKs, etc.).

6. Children's Privacy

開車GO does not collect personal information from users and is suitable for ages 4+.

7. Changes to This Policy

Any changes will be published on this page in sync with the corresponding App update.

8. Contact Us

If you have any questions about this Privacy Policy, please email: thsiao4000@gmail.com
